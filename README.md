# Desvie!

Jogo arcade responsivo feito apenas com HTML, CSS e JavaScript puro. Desvie dos blocos vermelhos, sobreviva o máximo possível e supere seu recorde — salvo localmente no navegador.

## Executar localmente

Não é necessária instalação: abra `index.html` em um navegador moderno.

## Publicar no GitHub Pages

Este repositório já está configurado para publicar a partir da branch `main`.

1. Abra **Settings > Pages** no repositório.
2. Em **Build and deployment**, confirme **Deploy from a branch**.
3. Selecione a branch `main` e a pasta `/(root)`.
4. Salve e aguarde a publicação.

A URL do jogo é: https://Alvaro-TM-pgm.github.io/desvie/

## Estrutura

```
.
├── index.html    # interface
├── style.css     # visual e responsividade
├── script.js     # gameplay, controles e recorde
├── README.md
└── .gitignore
```

## Controles

- Teclado: setas esquerda/direita ou A/D.
- Celular: botões direcionais abaixo da área do jogo.
